# Cleaniq Nigeria

Separate from the UK Cleaniq project (~/cleaniq). Nothing here is shared with it.

| Folder | What |
|---|---|
| `web/` | Nigeria website — React, Tailwind CSS, Framer Motion (Vite). Starting with the landing page. |
| `customer-app/` | Nigeria customer app (to come) |
| `worker-app/` | Nigeria worker app (to come) |

## Run the website

```
cd web
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in web/dist
```
